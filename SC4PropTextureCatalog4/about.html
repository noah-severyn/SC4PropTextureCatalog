About

This project was originally inspired by the original Prop & Texture Photo Catalog started in 2011, and aims to index all known TGIs and plugin packs for SimCity 4, especially focusing all known dependencies. This project also builds upon the Plugin Pack ID Index list assembled by catty-cb in 2018. This iteration of the catalog is assembled and is maintained by nos.17. Assistance has additionally been provided from STEX Custodian (Tyberius06), Cyclone Boom, and CorinaMarie.

I aim for this tool to assist many content creators (especially lotters) who are looking for more and better content to incorporate into their work. Looking for a motorcycle to add to your lot? Filter only prop packs that contain vehicles and/or motorcycles. Looking for seasonal trees? Look through all packs that contain seasonal trees until you can find the right ones for you? Want to use all HD? Scour all packs that contain High Definition props to find the ones you want.

Found a bug? Am I missing a prop or texture pack? Have an idea for additional sorting/filtering categories? Is there a better way to make the Catalog more interactive or useful? I would very much like to hear from you! Visit the SimCity 4 Prop and Texture Catalog thread or open an issue in Github. The source code for this project is hosted in the SC4PropTextureCatalog Github repository.
