Search for a Plugin Pack Id

If you have a missing building plugin and load into a city, a dialog will appear listing all the missing Plugin Pack Ids as hexadecimal numbers. These are very difficult to look up and to make any use of, so this was created to allow users to look up these ids and figure out what file they belonged in. The file name would hopefully provide clues for the building name or creator which could give a starting point to figure out what was missing. The data was provided courtesy of catty-cb, who originally compiled the data in her Plugin pack ID Indexes. I reorganized it into a database and created the search feature for easier access.

This feature has been obsoleted in favor of null45's Query Tool UI Extensions DLL. The DLL has a configurable option, LogBuildingPluginPath, which when set to true will record the building name and plugin file path in a log file when the missing item is queried. This method is much more reliable as it does not rely on a gigantic database of every known building and lot to be able to tell you the name of the file missing a building.
